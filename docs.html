#Overview

BlackTools is a complete channel-management script for Eggdrop bots. It bundles ~70 commands, 25+ protections (flood, spam, advert, badword, clone detection…) and 25+ modules (seen, quotes, notes, greets, topic control, X integration…) into one package. Every channel can be configured independently — each owner/manager toggles the protections, modules and commands they want.

The two most important commands: !h shows every command available to you at your access level, and !man <command> shows the built-in manual page for any command, protection or module. When in doubt — !man it.

#What's new in 3.0.0

This version merges the upstream BlackTools-3.0 branch (2023–2025, never merged into the 2.5.x line) with the fork's 2.5.x work.

IMPORTANT — not backwards compatible:
  • Alias: an alias can now chain commands with | (.alias add hello op %1 | voice %1). An existing alias whose command has a literal | (a badword regex such as a|b, say) is now split there: edit or recreate it.
  • repetitivechars: now flags a run of N identical characters anywhere in the line (before: only at the end) and ignores spaces. A limit that is not a number, or is lower than 2, turns the check off instead of flagging everything.
  • Idle: the WHOIS answers are matched to the channel that asked (before, a bot on several channels used the last channel scanned for all of them).
  • Updating: bots installed from upstream must have the files replaced by hand once to start following this repository. VERSION says STATUS 1: restart the bot after the update.
ChangeDescription
idle +bNew Idle-Ban option (off by default): bans regular users who idle longer than idlebanmax. Never applied to ops, voices, halfops, users with the except flags or f, or services. Settings: idlebanmax, idleban-reason, idleban-bantime, idleban-banmask. !man idle.
disablepubcmdsNew per-channel setting (off by default): commands given with the command character are ignored on the channel. botnick command, private messages and DCC still work. !man disablepubcmds.
AliasAn alias can run several BlackTools commands in a row, separated by |.
!seenA search on all channels no longer shows entries from private (+p) or secret (+s) channels.
AutoUpdateThe download is unpacked only when complete, and gives up after 10 minutes.
NotesThe handle of a note is compared without regard to case.

#Installation

From the INSTALL file — how to get BlackTools running on a fresh eggdrop.

shell
# 1. get the latest version (or unpack the release archive)
git clone https://github.com/tclscripts/BlackToolS-TCL

# 2. edit BlackTools.tcl to your liking (homechan, cmdchar, X login, defaults…)

# 3. copy everything into your eggdrop's scripts/ directory (case sensitive!)
cp -r BlackTools/    /home/of/your_eggdrop/scripts/
cp BlackTools.tcl    /home/of/your_eggdrop/scripts/

# 4. add this line at the END of your eggdrop config file
source scripts/BlackTools.tcl

# 5. restart the eggdrop, then in any channel type:
.h
Warning: running BlackTools together with the A&A script "works in theory" only — the author explicitly does not support that combination.

The directory layout that must live under scripts/:

BlackTools.tcl — main config BlackTools/BT.Core.tcl BlackTools/BT.Ban.tcl — ban engine BlackTools/BT.Loader.tcl BlackTools/BT.Binds.tcl BlackTools/BT.Timers.tcl BlackTools/Addons/ — http, json, github BlackTools/Commands/ — 10 files BlackTools/Modules/ — 26 files BlackTools/Protections/ — 19 files BlackTools/lang/ — EN · RO · ES · FR

#Using the bot

Every BlackTools command can be triggered four ways. All examples in this documentation use !, but the bot answers to any of the configured trigger characters (stock: ! . ` ^ — change them with set cmdchar) — plus the botnick prefix, private message, and (new in 2.5.5) DCC chat.

syntax
!command <args>                       # trigger char, in the channel
BotNick command <args>                # address the bot by nick, in the channel
/msg BotNick command #channel <args>  # private message — add the #channel
.bt command [#channel] <args>         # DCC party-line (channel optional with myset mychan)
Convention used below: <required> arguments are mandatory, [optional] arguments may be omitted. [#chan] is only needed when messaging the bot privately or acting on another channel. Durations are written 10m (minutes), 3h (hours), 2d (days) — and 0 means permanent.

The help menu

!h

Any access

The most important command. Shows all commands available at your access level, plus category submenus. Disabled commands are hidden or greyed out.

syntax
!h [category]       # categories: cmds · ban · add · manager · master · owner
                      #             btinfo · chaninfo · module · egg
examples
!h                    # your main menu
!h ban                # every kick/ban command you can use
!h module             # which modules are ON (+) or OFF (-) on #channel
!h chaninfo           # channel flags & eggdrop flood settings
/msg BotNick h #channel ban

!man

Any access

The built-in user manual. Displays usage information for every command, protection and module — the same content as this page, live on IRC. It also points users to this page, for reading the syntax more calmly: the address is black(docs_url) in BlackTools.tcl (set it to "" to turn this off, or to your own copy of docs.html).

syntax
!man <command>
examples
!man b                # manual for the ban command
!man antipub          # manual for the anti-advertising protection
!man banmethod        # explains the 7 punishment methods

#Access levels

BlackTools layers its own named levels on top of eggdrop flags. Channel levels apply per-channel; global levels apply bot-wide. Each level inherits everything below it.

LevelScopeEggdrop flagTypical powers
Voicechannel|Vvoice self, seen, invite, kick/warn, myset, h/man
Opchannel|O+ op/deop, modes, topic, cycle, most ban commands
Adminchannel|A+ say/act, add users, suspend, black/stick bans, stats
Managerchannel|M+ set/unset channel settings, enable/disable commands, exempt, purge, del/chuser
Masterglobalomanager powers on every channel + addchan/delchan, suspend chans, status
Ownerglobalm+ global bans, broadcast, die/restart/jump, cp, TCL loading
Boss ownerglobalneverything, incl. editing eggdrop.conf settings from IRC (egg)
Two auxiliary levels exist for the userlist: PROTECT (never punished by protections) and BAN (auto-banned on sight). Ops and voices can additionally be shielded per-channel with !set +oprotect / +vprotect / +hoprotect.

#General commands

Everyday commands available from the lowest access level upward.

!version

Any access

Displays the BlackTools version the eggdrop is running.

example
!version

!i  /  !invite

Voice+

Invites a user to the channel. The bot must be opped (@) for the invite to work.

syntax
!i <nick>          # in channel
/msg BotNick i #channel <nick>
example
!i JohnDoe           # invite JohnDoe to #channel

!seen

Voice+

Searches the per-channel seen database for a nick, IP or host (wildcards supported). Shows when the person was last seen and what they did. Owners+ can search global across all channels. Flood-protected (2 searches / 20s by default).

syntax
!seen <nick|ip|host>
!seen global <nick|ip|host>       # owners+ — all channels
examples
!seen JohnDoe
!seen *!*@*.videotron.ca

Related: +seen module toggle · +seenlastmsg (show last message) · +seenreply (notify people they were searched for)

!activ

Voice+

Shows the last recorded channel activity of a user (last join, part, kick, ban, text…), pulled from the bot's action tracker.

syntax
!activ <nick>

!for

Voice+

Makes multiple eggdrops (all running BlackTools) execute the same command simultaneously — handy when several bots guard the channel.

syntax
for <botnick1>,<botnick2>.. <command> [option]
example
for Bot1,Bot2 say Good morning everyone!

!info

Admin+

Displays database information about a user or a channel: access level, added hostmasks, automode, greet line, last-seen info, channel topic/URL/manager, and more.

syntax
!info <handle|#chan>
examples
!info JohnDoe
!info #channel

!addinfo

Voice+

Sets a personalised greeting line for yourself, shown in !info and announced by the bot when you join (requires +greet on the channel). Same as !myset greet.

syntax
!addinfo <text|reset>
example
!addinfo Hello everyone, glad to be here!

Op/voice management, modes, topic and channel messages.

Op+

Gives or removes halfop (+h %) for the specified users. !ho + / !ho - perform a mass halfop / dehalfop.

syntax
!ho [nick1] [nick2]..

Op+

syntax
!mode <+/-modes>

Op+

#Kick & ban commands

The heart of BlackTools: a full ban system with per-ban levels, durations, sticky bans, global bans, comments and searchable banlists. Durations: minutes / hours / days, 0 = permanent. Most commands accept a nick or a mask — if the nick isn't on the channel, the bot will WHOIS it.

!k

Voice+

Kicks a user (or everyone matching a mask) from the channel.

syntax
!k <nick|mask> [reason]
examples
!k Troublemaker
!k Troublemaker Please keep it civil

Optional settings: k-reason (default kick reason)

!w

Voice+

Delivers a warning kick — a kick with a configurable warning reason and message.

syntax
!w <nick>

Optional settings: w-reason · w-message

!b

Op+

The main ban command. Bans a nick or mask for a duration (stock default: 2 days). A duration of 0 makes the ban permanent (blacklisted). -level protects the ban from removal by lower access. Owners+ can add global (all channels) or link (linked channels). -c comment attaches a note visible on the ban entry. Supports CIDR masks like *!*@192.168.0.1/17 — and, new in 2.5.5, regex bans with -regex, matched against nick!ident@host/[realname]/[banmask type] (bracketed fields optional).

syntax
!b [-regex] <nick|mask|regex> [-level] [duration] [reason] [-c comment]
!b [-regex] <nick|mask|regex> [-level] [duration] [global|link] [reason]   # owner+
examples
!b SpamGuy 2d advertising
!b *!*@198.51.100.* 12h botnet range
!b Griefer -400 0 permanent, level 400 protection
!b Flooder 3d flooding -c third offence this week
!b -regex [a-z]+[0-9][0-9]!*@* 1d drone pattern

Optional settings: b-reason · b-bantime (default 2d) · b-banmask (default *!*@host)

!ub

Op+

Removes a ban by nick, mask or ban ID (wildcards supported). If the nick isn't on channel the bot WHOISes and unbans by ident/host/nick — matching regex bans are removed too. Use -regex to remove a stored regex ban directly. Careful: !ub * removes all channel bans.

syntax
!ub [-regex] <nick|mask|id|regex> [global|link]
examples
!ub SpamGuy
!ub 1234              # by ban ID (see +showid / !sb)

!sb

Op+

Searches the banlist and shows full details of a ban — who set it, when, why, expiry, comment. Also matches and inspects regex bans (-regex).

syntax
!sb [-regex] <nick|mask|id|regex> [global]
example
!sb *!*@*.example.net

!banlist

Op+

Shows the active bans on the channel — all of them, only yours, other people's, regex bans only, gags only, or (owners+) the global list. Paged output; follow with -next for more entries.

syntax
!banlist <all|handle|regex|gag|other>
!banlist global                    # owner+

!black

Admin+

Bans a user permanently (blacklist). Equivalent to !b ... 0.

syntax
!black <nick|mask> [reason] [-c comment]
example
!black KnownTroll repeat offender -c do not remove

Optional settings: black-reason · black-banmask

!stick

Admin+

Sets a sticky ban: if anyone removes it from the channel banlist, the bot puts it right back. Stock default duration: 2 days.

syntax
!stick <nick|mask> [duration] [reason] [-c comment]

Optional settings: stick-reason · stick-bantime · stick-banmask

!n

Op+

Bans on the user's nickname (mask nick!*@*). Default: 2h.

syntax
!n <nick>

Optional settings: n-reason · n-bantime · n-banmask

!id

Op+

Bans on the user's ident (mask *!user@*). Given a nick, the bot grabs the ident automatically. Default: 2h.

syntax
!id <nick|ident>

Optional settings: id-reason · id-bantime · id-banmask

!mb

Op+

Bans a nickname automatically on ident, with an optional reason. Default: 2d.

syntax
!mb <nick> [reason]

Optional settings: mb-reason · mb-bantime

!dr

Op+

!dr <nick|mask>

!vr

Op+

Bans with a default VIRUS/TROJAN reason. Default: 3d.

syntax
!vr <nick|mask>

!bot

Op+

Bans with a default BOT reason — for unauthorised bots. Default: 7d.

syntax
!bot <nick|mask>

!spam

Op+

Bans with a default SPAM reason. Default: 7d.

syntax

Op+

Bans with a default bad word reason. Default: 1d.

syntax

!gag  /  !ungag

Op+

Silences a user — they can't write on the channel — for a period (default: 10m). The bot re-bans (+b with mute) if the gag is removed early. !ungag lifts it.

syntax
!gag <nick> [duration] [reason]
!ungag <nick|mask>
example
!gag LoudGuy 30m take a breather

Optional settings: gag-reason · gag-bantime · gag-banmask

!exempt

Manager+

Manages the ban-exempt list: hosts on it are never banned by the bot. Owners+ can make an exempt global.

syntax
!exempt add <ip|host> [period] [global] [reason]
!exempt list [global]
!exempt del <ip|host> [global]
example
!exempt add *!*@trusted.users.undernet.org 0 our regular helper

!stats

Admin+

Shows ban/command statistics for a user. Managers+ can reset. Requires the +banstats setting to collect data (see also !banstats total|reset).

syntax
!stats <handle> [total|reset]

!report

Everyone

Lets regular users (and voice/protect) report a nickname for adverts or spam. The bot relays the report to channel ops via @notice. Needs +reportnick and the bot opped. Flood-limited (2 reports / 60s).

syntax
!report <nick> <comment>
example
!report LinkSpammer keeps pasting shady links in PM

#User management

Adding people to the bot, hostmasks, automodes and suspensions. You can only act on users with access lower than your own.

!add

Admin+

Adds a user to the channel's userlist at a given level (voice, op, admin, manager…). If the user is on channel, their current hostmask is added (default style: *!*@host). If not, the Undernet default is used: *!*@<user>.users.undernet.org — so you can add people by X username.

syntax
!add <level> <nick|Xusername>
examples
!add op JohnDoe          # JohnDoe is on channel → current host added
!add voice SomeUserX     # not on channel → *!*@SomeUserX.users.undernet.org

!userlist

Admin+

Shows the channel's access list, filtered by level or all of it.

syntax
!userlist <level|all>       # levels: voice · op · admin · manager · owner · master
example
!userlist op

!delacc

Admin+

Removes a user's access from the channel (their record stays in the bot). Must target someone with lower access than you. Owners can strip global owner|master access too.

syntax
!delacc <handle>
!delacc <owner|master> <handle>       # remove a global level

!del

Manager+

Deletes a user entirely from the bot's database — all channels, all hosts.

syntax
!del <handle>

!auto

Admin+

Sets a user's automode — the bot automatically ops or voices them on join. The user must already have access on the channel. Owners+ can apply it -global.

syntax
!auto <+/-o> <nick|handle> [-global]       # auto-op
!auto <+/-v> <nick|handle> [-global]       # auto-voice
example
!auto +v JohnDoe

!s  /  !us

Admin+

!s suspends a user's access on the channel for a period (default: 2d); !us lifts the suspension. Only works downward in the hierarchy.

syntax
!s <handle> [duration] [reason]
!us <handle>
example
!s RogueOp 3d abusing kick command

!addhost  /  !delhost

Admin+

Adds or removes a hostmask on a user's record.

syntax
!addhost <handle> <mask>
!delhost <handle> <mask>
example
!addhost JohnDoe *!*@JohnDoe.users.undernet.org

!chuser

Manager+

Renames a user's handle in the bot's database.

syntax
!chuser <handle> <newhandle>

#Channel management

Settings, toggles and channel administration — the manager's toolbox.

!set

Manager+

The universal switchboard. Turns protections/modules on or off (+flag / -flag) and assigns values to string options. Owners+ can use global to apply a setting to every channel. See the Protections and Modules sections for every flag.

syntax
!set <+/-flag>                     # toggle
!set <option> <value>              # assign
!set global <option> <value>       # owner+ — all channels
examples
!set +antipub                     # enable anti-advertising
!set chanmode +ntk s3cret         # enforce modes incl. a key
!set b-bantime 4h                 # default !b duration → 4 hours
!set url https://www.example.com

!unset

Manager+

Resets a setting/option back to default. Owners+ can unset global.

syntax
!unset <flag|option>
!unset global <flag|option>

!show

Manager+

Shows the current value of any setting.

syntax
!show <setting>
example
!show antipub-bantime

!enable  /  !disable

Manager+

Enables/disables a command on the channel — for everyone or for a specific user. Masters+ can apply it globally (commands only, not users). Disabled commands show greyed-out in !h.

syntax
!disable <command|all> [user] [global]
!enable <command|all> [user] [global]
examples
!disable k TriggerHappyOp     # take !k away from one user
!enable all

!ignore

Manager+

Adds, lists or removes bot-level ignores (default duration: 6h).

syntax
!ignore add <ip|mask> [duration] [reason]
!ignore list
!ignore del <ip|host>

!purge

Manager+

Deletes the channel from the bot's channel database (manager-only variant of delchan).

syntax
!purge <#chan> <reason>

!addchan  /  !delchan

Master+

Adds a channel to the bot (it joins immediately; an optional key is used to get in) or removes one.

syntax
!addchan <#chan> [key]
!delchan <#chan> <reason>

!suspend  /  !unsuspend

Master+

Suspends a channel — the bot leaves and won't join or act in it — or reverses that.

syntax
!suspend <#chan> <reason>
!unsuspend <#chan>

!channels

Master+

Lists all channels the bot is joined to (channels flagged +invisible are hidden from non-boss users).

syntax
!channels

!cp

Owner+

Copies configuration from one channel to another.

syntax

Owner+

ChanLink module — synchronises bans across two or more channels: a ban added on one linked channel is mirrored to the others (and removed everywhere on unban).

#Ban methods, masks & durations

The 7 ban methods

Every protection has a -banmethod setting choosing how offenders are escalated. Counters expire after banmethod-expire (60m here). Set with !set <protection>-banmethod <n>.

#Escalation
1warnjust a warning kick/notice
2kick
3banstraight to ban
4warn → kicksecond offence gets the kick
5warn → kick → banthe full ladder
6kick → ban
7warn → ban

The 5 banmask styles

Every ban command has a -banmask setting choosing the mask shape, built from nick!user@host:

#MaskBans on…
1*!*@hosthost only (the usual default)
2*!user@hostident + host
3nick!user@hostthe exact triple
4nick!*@*nickname only
5*!user@*ident only
Webchat users (mibbit, kiwiirc, irccloud…) are automatically banned on ident only regardless of the mask setting — their host is shared, their ident carries the user's hex IP.

Durations

10m — ten minutes 3h — three hours 2d — two days 0 — permanent

Good to know

CIDR bans work: !b *!*@192.0.2.1/24 bans the whole range.
Ban comments: nearly every ban command accepts -c <comment> — other ops see it when they inspect the ban with !sb.
Full banlist handling: when the channel +b list fills up (Undernet numeric 478), the bot auto-removes the 10 oldest bans, holding +m for 10 seconds while it cleans.
Multi-sentence texts: greets, quotes, ads and notes split on ~ — text1~text2 is delivered as two lines.
